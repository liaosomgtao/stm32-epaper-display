# 基于 STM32F103 + FreeRTOS 的 SPI 水墨屏驱动与显示

基于 STM32F103 与 FreeRTOS 完成水墨屏（电子纸）的 SPI 接口驱动，封装 **全局刷新** 与 **局部刷新** 两个接口，支持数字时钟与预设图案的显示与切换。基于 FreeRTOS 创建「显示刷新」与「按键响应」两个独立任务，实现按键切换显示内容、交互响应及时。

## 功能特性

- 水墨屏 SPI 接口驱动编写（SPI1，软件 CS/DC/RST 控制）
- 全局刷新 / 局部刷新两个接口封装
- 数字时钟（HH:MM:SS）显示，秒级更新
- 预设图案显示
- FreeRTOS 双任务：显示刷新任务 + 按键响应任务，通过队列通信
- 按键切换显示内容，人机交互响应及时

## 硬件清单与接线

| 模块 | 引脚 | 说明 |
|------|------|------|
| STM32F103 | — | 主控 |
| 水墨屏（2.9" 296×128，SSD1680）SCK | **PA5** | SPI1 时钟 |
| 水墨屏 MOSI（DIN） | **PA7** | SPI1 数据 |
| 水墨屏 CS | **PB0** | 片选（软件控制） |
| 水墨屏 DC | **PB1** | 数据/命令选择 |
| 水墨屏 RST | **PB2** | 复位 |
| 水墨屏 BUSY | **PB3** | 忙信号（输入） |
| 按键（一端接 GND） | **PA0** | 显示切换（低电平有效，内部上拉） |

> 驱动按 2.9 寸黑白 SSD1680（296×128）编写，命令集与 SSD16xx 系列通用，换其他尺寸只需改 `EPD_WIDTH/EPD_HEIGHT` 与初始化参数。

## 软件架构

```
                 ┌────────────────────────────┐
                 │         FreeRTOS           │
 按键 ──▶  ButtonTask ──(队列)──▶ DisplayTask ──▶ SPI1 ──▶ 水墨屏
 (PA0)   (去抖/切换)   modeQueue  (刷新/走时)            (SSD1680)
                 └────────────────────────────┘
```

- **DisplayTask（显示刷新任务）**：每 1s 走时并局部刷新时钟；收到队列里的模式切换消息后，用全局刷新切换时钟/图案。
- **ButtonTask（按键响应任务）**：按键去抖，按下后切换模式，通过队列通知显示任务。

## 关键技术点

1. **全局刷新 vs 局部刷新**：全局刷新用 `DISPLAY UPDATE CONTROL 2 = 0xC7`，局部刷新用 `0x0F` 并配合 `SET RAM X/Y` 缩小刷新窗口，减少刷新时间与闪烁。
2. **刷新闪烁优化**：通过查阅数据手册调整驱动时序（BUSY 等待、复位延时），改善刷新效果。
3. **FreeRTOS 任务划分**：显示与按键解耦，队列传递模式，按键响应不受屏刷新的 2s 忙等待影响。

## 编译运行（STM32CubeIDE）

1. STM32CubeMX 新建工程：芯片 `STM32F103C8Tx`，时钟 HSE=8MHz、主频 72MHz。
2. 开启 `SPI1`（Master，PA5/PA7，Mode0，预分频 8 约 9MHz）、`FreeRTOS`（CMSIS_RTOS_V2，或直接用 FreeRTOS 内核）。
3. 配置 GPIO：PB0/PB1/PB2 输出、PB3 输入（BUSY）、PA0 输入上拉（按键）。
4. 生成工程，加入本仓库 `Inc/epaper.h`、`Src/epaper.c`，`main.c` 以本仓库为模板（注意 FreeRTOS 任务代码）。
5. 编译烧录后，屏幕显示数字时钟，按 PA0 键在「时钟 / 图案」间切换。

> 启用 FreeRTOS 后，CubeMX 会提示把 HAL 时基从 SysTick 改为 TIM6，按提示操作即可（本代码任务内均使用 `vTaskDelay`）。
